## Authored Lesson Notes

### k-001: Structural Assignability

- **Objective:** Read assignability direction as a comparison between required guarantees, and predict how annotations expose a minimum structural contract.
- **Prerequisites:** Familiarity with ordinary object, interface, class, function, array, tuple, optional-property, and readonly syntax.
- **Drill dimensions:** Rich source versus narrow target, annotated versus inferred views, optional members, readonly permissions, methods and class instances, and container structures.
- **Edge cases:** Fresh object-literal checks, exact optional properties, permissive readonly object assignment, readonly arrays, private identity, weak types, index signatures, `{}` versus `object`, function arity, and instance/static separation.

### k-002: Any, Unknown, and Never

- **Objective:** Distinguish the safe top type, the bottom type, and the checker escape hatch by following their guarantees, assignment direction, and propagation through larger types.
- **Prerequisites:** `k-001` structural assignability; familiarity with unions, intersections, arrays, functions, and ordinary runtime guards.
- **Drill dimensions:** Special-type classification, source-to-target assignability, union absorption, intersection identity and annihilation, element versus container types, promises, and function results.
- **Edge cases:** Property access, `keyof`, distributive `never`, tuple-wrapped conditionals, conditional `any`, utility-type propagation, strict equality, detector design, catch variables, never-returning functions, `Record<string, never>`, and containing `JSON.parse`.

### k-003: Union and Intersection Algebra

- **Objective:** Read unions as additional possible values with fewer shared guarantees, and intersections as simultaneous requirements with fewer inhabitants and more available members.
- **Prerequisites:** `k-001` structural assignability and `k-002` top, bottom, and escape-hatch behavior; familiarity with object, tuple, array, and function types.
- **Drill dimensions:** Literal normalization, overlap and span, object-union shared members, object-intersection composition, algebraic laws, top and bottom identities, containers, tuples, and callable utility types.
- **Edge cases:** Strict representation versus mutual assignability, intersection flattening, impossible properties versus impossible objects, discriminant reduction, `keyof` reversal, callable unions and overload-like intersections, last-signature extraction, and correlation loss in records of independent unions.

### k-004: Literal Widening, As Const, and Satisfies

- **Objective:** Predict when literal information widens, distinguish binding immutability from value preservation, and choose among annotations, assertions, `as const`, `satisfies`, and `as const satisfies` for public views and validated registries.
- **Prerequisites:** `k-001` assignability and excess-property checks, plus `k-003` literal unions; familiarity with mutable objects, arrays, tuples, readonly properties, and template-literal syntax.
- **Drill dimensions:** Const versus let primitives, mutable property and array inference, explicit annotations and assertions, deep literal syntax, spreads and references, contextual `satisfies` inference, exact record keys, mutable and readonly tuple constraints, and combined preservation plus validation.
- **Edge cases:** Compile-time versus runtime immutability, syntax restrictions on const assertions, shallow preservation across references, spread widening, boolean-literal retention, tuple contextual typing, readonly constraints that retain mutable expressions, fresh versus stale excess-property checks, forced assertions, function-return widening, conditional expressions, and tuple destructuring.

### k-005: Generic Function Inference

- **Objective:** Trace candidate collection, type-argument selection, and substitution through generic function calls, and distinguish inferred relationships from explicit instantiation.
- **Prerequisites:** `k-004` literal widening and preservation; familiarity with function types, callbacks, arrays, readonly tuples, and static versus runtime values.
- **Drill dimensions:** Direct primitive candidates, widened variables, mutable and preserved structures, wrapper substitution, element inference, independent type parameters, callbacks and factories, generic references, and instantiation expressions.
- **Edge cases:** Candidate-free parameters, `any` and `unknown` propagation, empty arrays and `never`, current control-flow types, explicit-argument rejection, readonly element unions, generic function assignability, and generic call signatures returned as values.

### k-006: Parameter-Site Inference

- **Objective:** Locate direct and nested parameter occurrences that contribute inference candidates, and distinguish argument evidence from contextual callback typing.
- **Prerequisites:** `k-005` generic call inference; familiarity with structural object matching, arrays, callbacks, optional parameters, rest parameters, and excess-property checking.
- **Drill dimensions:** Direct sites, nested boxes and payloads, mutable and readonly element sites, value-driven callback context, annotated consumers, omitted optionals, explicit type arguments, and rest collections.
- **Edge cases:** Missing candidates, empty-array `never`, `any` and `unknown`, fresh versus stored outer objects, widened nested properties, readonly literal extraction, contravariant consumer annotations, explicit mismatches, and current static views.

### k-007: Contextual Return Inference

- **Objective:** Distinguish callback-return candidates, expected-result context, and post-inference assignability, including context propagated through array, function, and promise shells.
- **Prerequisites:** `k-005` generic substitution and `k-006` parameter-site evidence; familiarity with callback returns, annotations, promises, literal widening, and control-flow-narrowed bindings.
- **Drill dimensions:** Factory returns, independent mapper outputs, output-only parameters, contextual arrays, deferred functions, promises, explicit return annotations, explicit type arguments, and preserved literals.
- **Edge cases:** No-context `unknown`, unsafe output-only implementations, conditional literal unions, contextual `void`, structural extra properties, conflicting input evidence, current narrowing beneath broad annotations, async returns, and context through nested callbacks.

### k-008: Generic Constraints

- **Objective:** Read a generic constraint as a minimum admissible contract, distinguish it from the inferred subtype, and predict when a return preserves that subtype or exposes only the constraint view.
- **Prerequisites:** `k-001` structural assignability and `k-005` generic inference; familiarity with literal unions, intersections, object spreads, readonly properties, and explicit type arguments.
- **Drill dimensions:** Shared structural capabilities, rich subtype preservation, deliberate return-view erasure, primitive literal-union bounds, explicit family selection, object bounds, intersection bounds, arrays, functions, maps, and timestamp composition.
- **Edge cases:** Missing, optional, readonly, getter, and union members; fresh versus stored rich sources; `{}` versus `object`; primitive rejection; `any`, `unknown`, and `never`; widened evidence; explicit bounds; nested view erasure; and unsimplified conflicting property intersections.

### k-009: Keyof Semantics

- **Objective:** Compute the property-key union guaranteed by a static type and distinguish key-space reasoning from runtime property enumeration.
- **Prerequisites:** `k-001` structural surfaces, `k-002` special types, and `k-003` union/intersection guarantees; familiarity with object members, index signatures, arrays, tuples, symbols, and classes.
- **Drill dimensions:** Required, optional, readonly, and method keys; string, numeric, and unique-symbol declarations; broad index domains; `Record`; mutable and readonly collection APIs; tuple index membership; and union/intersection key reversal.
- **Edge cases:** `Object.keys` versus `Reflect.ownKeys`, symbol omission, numeric stringification, enumerability and inheritance, primitive wrapper keys, callable surfaces, public instance versus constructor keys, `any`/`unknown`/`never`, empty object types, optional common keys, and indexed union alternatives.

### k-010: Indexed Access Types

- **Objective:** Project value types with `T[K]`, union results across multiple keys, and compose lookups through nested objects, arrays, and tuples.
- **Prerequisites:** `k-009` key-space semantics and `k-008` related generic constraints; familiarity with optional properties, records, arrays, tuples, and unique-symbol keys.
- **Drill dimensions:** Literal property lookup, modifier effects, union-key projection, all-values unions, string and number index signatures, array elements, tuple positions and element unions, nested APIs, and inferred getter/pluck results.
- **Edge cases:** Optional versus explicit `undefined`, `Required` and `Partial`, control-flow-narrowed key variables, common union keys, invalid tuple positions, string-index numeric lookup, optional/rest tuples, `any`/`unknown`/`never`, never-valued properties, and symbol identity.

### k-011: Related Type Parameters

- **Objective:** Encode and follow dependencies between an object type, one or more selected key types, their projected values, and independently inferred transformation results.
- **Prerequisites:** `k-008` constraints, `k-009` key spaces, and `k-010` indexed access; familiarity with callbacks, `Pick`, mutable assignment, arrays, tuples, and union keys.
- **Drill dimensions:** Single and paired selection, union-valued keys, positional tuple results, dependent callback inputs, independent callback outputs, key-list projections, empty selections, dictionaries, tuples, numeric keys, and unique-symbol keys.
- **Edge cases:** Literal versus union-key writes, optional and readonly sources, invalid keys, object unions restricted to common keys, impossible discriminant intersections, empty `Pick`, unchecked string indexes, `any`/`unknown`/`never`, current control-flow keys, and the loss of key/value correlation under union K.

### k-012: Generic Defaults

- **Objective:** Decide whether each generic slot is supplied by an explicit argument, inference, or a default, and use dependent and constrained defaults without confusing them with runtime value defaults.
- **Prerequisites:** `k-005` inference, `k-008` constraints, and `k-011` parameter dependencies; familiarity with optional parameters, rest arguments, maps, unions, and special types.
- **Drill dimensions:** Omitted versus inferred single slots, preserved and widened evidence, dependent second parameters, empty rest calls, explicit empty collections, trailing partial instantiation, key/value registries, constrained options, rich subtypes, and readonly inputs.
